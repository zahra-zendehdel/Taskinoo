# تسکینو | Taskinoo

اپلیکیشن وب مدیریت کارهای روزانه — ساخته‌شده با Flask، ذخیره‌سازی JSON، بدون نیاز به لاگین.

## اجرای پروژه

```bash
pip install -r requirements.txt
python app.py
```

سپس مرورگر رو باز کن روی: http://127.0.0.1:5000

## امکانات

- افزودن / ویرایش عنوان / حذف کار
- تعیین دسته‌بندی و سررسید برای هر کار
- تنظیم درصد پیشرفت هر کار با اسلایدر
- **تقویم شمسی ماهانه** با نمایش فعالیت روزانه (هرچه رنگ پررنگ‌تر، فعالیت بیشتر)
- نمودار پیشرفت هر کار به‌صورت جداگانه
- **نمودار روند پیشرفت کلی** (میانگین پیشرفت همه‌ی کارها در طول زمان، به‌سبک نمودارهای بورسی)
- یک جمله‌ی انگیزشی تازه در هر روز
- تم شب / روز با یک دکمه (ترجیح شما ذخیره می‌شه)

## ساختار داده

همه‌چیز در فایل `data/db.json` ذخیره می‌شه:

```json
{
  "next_id": 1,
  "tasks": [...],
  "activity": { "2026-08-17": 3 },
  "history": [ { "date": "2026-08-17", "avg_progress": 42.5 } ]
}
```

جمله‌های انگیزشی هم در `data/quotes.json` قرار دارن — می‌تونی خودت جمله اضافه یا حذف کنی.

## نکته درباره تقویم

تقویم اپ **شمسی (جلالی)** هست چون این پروژه برای کاربر فارسی‌زبان طراحی شده. تبدیل تاریخ در فایل `jalali.py` به‌صورت کاملاً مستقل (بدون کتابخانه‌ی خارجی) پیاده شده. فیلد سررسید هر کار همچنان با تقویم میلادی (استاندارد HTML) پر می‌شه.
